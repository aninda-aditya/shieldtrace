# Security Policy

## Supported Versions

Currently, only the latest release (v0.1.0 and above) is supported with security updates.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a vulnerability in ShieldTrace, please report it responsibly:
1. Send an email to krishnaaditya24nov@gmail.com
2. Include a detailed description of the issue and steps to reproduce it.
3. I will acknowledge your report within 48 hours and work on a patch.

Thank you for helping keep ShieldTrace safe!
